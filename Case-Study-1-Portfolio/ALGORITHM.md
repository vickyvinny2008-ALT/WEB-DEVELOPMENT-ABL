# Algorithm – Personal Portfolio Website
1. Start.
2. Create the HTML document and connect the CSS stylesheet.
3. Add the portfolio title and navigation hyperlinks.
4. Add the profile image and introduction.
5. Add separate sections for about, education, skills, hobbies, projects, achievements and contact details.
6. Add ordered and unordered lists where information is grouped.
7. Add same-page anchor links to move between sections.
8. Apply colours, fonts, text alignment, borders, margins, padding, width and height using CSS.
9. Open the HTML file in a web browser and inspect each section and link.
10. Stop.
