# Algorithm – College Information and Admissions Website
1. Start.
2. Create the HTML document and link the CSS stylesheet.
3. Add the college name and navigation hyperlinks.
4. Create sections for institutional information, courses and departments.
5. Add faculty and student activity information.
6. Add campus facilities with images and lists.
7. Add admission procedure and contact details.
8. Add anchor links for navigation within the same document.
9. Apply syllabus CSS properties for typography, colours, backgrounds, borders, width, height, margins and padding.
10. Open the page in a browser and test navigation and image display.
11. Stop.
