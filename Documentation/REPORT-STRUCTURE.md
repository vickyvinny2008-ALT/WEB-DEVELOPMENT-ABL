# Consolidated ABL Report – Suggested Structure

1. Cover page: subject, assignment title, student name, roll number, branch, section and academic year.
2. Introduction: objective of the Web Development ABL activity.
3. Syllabus scope: Units I, II and III topics used in the implementation.
4. Case Study 1 – Personal Portfolio Website: problem description, objectives, algorithm, flowchart, source-code summary, test cases and execution screenshots.
5. Case Study 2 – College Information and Admissions Website: problem description, objectives, algorithm, flowchart, source-code summary, test cases and execution screenshots.
6. Case Study 3 – Tourism and Heritage Information Website: problem description, objectives, algorithm, flowchart, source-code summary, test cases and execution screenshots.
7. Result and learning outcomes.
8. GitHub repository link.

Insert genuine screenshots captured after opening each `index.html` page in a browser. Do not label mockups or placeholder graphics as execution screenshots.
