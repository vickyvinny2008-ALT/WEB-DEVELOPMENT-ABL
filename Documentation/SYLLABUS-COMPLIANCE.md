# Syllabus Compliance Record

This project is intentionally limited to the supplied Subject 3: Web Development syllabus, Units I–III.

## Unit I – Introduction to Web Development and HTML Fundamentals
- HTML basics, document structure and HTML elements.
- CSS fundamentals, container elements and class attributes.
- CSS syntax, text alignment, text colour and background colour.

## Unit II – User Interface Design and CSS Fundamentals
- CSS text properties, multiple rules and rulesets.
- Font family, font size, text decoration and font style.
- CSS box model using width, height, border, padding and margin.
- Background image and background size concepts.
- HTML elements, image elements, void elements, ordered and unordered lists and list-style-type.
- UI/UX fundamentals, visual design principles, colour theory, typography, information architecture, wireframing, prototyping, design thinking, accessibility and mobile-first design principles.

## Unit III – HTML5, Semantics and Advanced CSS
- Web infrastructure and hyperlinks.
- Anchor elements and navigation within the same document.
- Images as links, line breaks and horizontal rules.
- HTML5 document features.

## Excluded from implementation
JavaScript, frameworks, CSS Grid, Flexbox, animations, transitions, backend programming and database connectivity are not used. CSS media queries and properties not listed in the supplied syllabus are also avoided. The pages are static demonstrations.

## Review note
The syllabus names design principles such as mobile-first design, but does not list the CSS media-query syntax. The implementation therefore uses simple document flow and does not claim breakpoint-based responsiveness.
