# Web Development Activity-Based Learning

Three static website case studies developed using only the topics listed in the supplied Subject 3 syllabus (Units I–III).

## Case studies
1. Personal Portfolio Website
2. College Information and Admissions Website
3. Tourism and Heritage Information Website

## Technologies and syllabus scope
- HTML / HTML5 structure and elements
- CSS syntax, class attributes, containers and text properties
- Font family, font size, text decoration and font style
- Text alignment and text/background colours (including hexadecimal colours)
- Width, height, borders, padding, margin and the CSS box model
- Background images and background sizing
- Images, ordered lists, unordered lists and list-style-type
- Hyperlinks, anchor elements, same-document navigation, image links, line breaks and horizontal rules
- UI/UX principles, typography, colour theory, information architecture, wireframing, accessibility and mobile-first design

## Deliberately not used
JavaScript, frameworks, CSS Grid, Flexbox, animations, transitions, backend code and database connectivity are not used.
