# Algorithm – Tourism and Heritage Information Website
1. Start.
2. Create the HTML document and connect the CSS stylesheet.
3. Add the tourism website title and navigation links.
4. Add an introductory banner and destination information.
5. Add images and descriptions for selected destinations.
6. Add heritage, culture, festival and cuisine information.
7. Add travel tips and contact information.
8. Add ordered and unordered lists for grouped information.
9. Add same-document anchor links for navigation.
10. Apply syllabus CSS properties for fonts, colours, backgrounds, borders, width, height, margin and padding.
11. Open the webpage in a browser and check images and links.
12. Stop.
